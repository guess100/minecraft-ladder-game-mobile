참가 가이드

내 폰으로 QR만 찍으면 바로 게임에 참가할 수 있어요.
앱 설치·회원가입은 필요 없어요.

1QR 찍기 — 큰 화면의 QR을 폰 카메라로 찍어요
2팀 고르기 — 우리 팀을 누르거나, 새 팀 이름(개인전은 내 이름)을 입력해요
3게임하기 — 진행자가 시작하면 폰 화면 안내대로!

1입장하기

  1. 폰의 기본 카메라 앱을 켜고, 큰 화면에 보이는 QR 코드를 비춰요.
  2. 화면에 뜨는 링크를 누르면 참가 화면이 열려요.

QR이 안 찍히면? 인터넷 주소창에 https://guess100.github.io/minecraft-ladder-game-mobile/를 입력하고, 첫 화면의 참가하기 칸에 큰 화면의 방 코드 5자리를 입력하세요.

와이파이·LTE·5G 모두 괜찮아요. 데이터 사용량도 아주 적어요.

2팀 고르기 (또는 이름 입력)

👥 팀전일 때

  • 우리 팀이 이미 있으면 팀 이름을 눌러서 합류해요.
  • 우리 팀이 없으면 아래 칸에 팀 이름을 입력하고 입장을 눌러요. 팀의 첫 번째 사람이 만들면 돼요.
  • 같은 팀 사람끼리는 꼭 같은 팀을 골라 주세요. 비슷한 이름으로 팀이 두 개 생기지 않게 조심!

🙋 개인전일 때

  • 내 이름을 입력하고 입장을 눌러요.
  • 같은 이름이 이미 있으면 홍길동2처럼 조금 다르게 입력해 주세요.

입장하면 대기 화면에 우리 팀(나)의 순위와 점수가 보여요.

팀을 잘못 골랐다면? 대기 화면 아래 팀 바꾸기를 누르세요 (팀전만).

3게임하기

  1. 게임 안내가 폰에 떠요. 방법을 읽고 진행자의 시작을 기다려요.
  2. 3·2·1 카운트다운 후 바로 시작! 시간은 화면 위에 보여요.
  3. 시간이 끝나면 "끝!"이 뜨고, 잠시 뒤 우리 팀 순위와 받은 점수가 나와요.
팀전에서 폰이 여러 대면? 같은 팀 폰들의 평균이 팀 기록이 돼요. 그래서 보통 팀마다 폰 1대로 하고, 게임마다 팀원이 돌아가며 출전해요.
점수는 어떻게? 게임마다 등수가 높을수록 점수를 더 받아요. 모든 게임 점수를 합쳐 최종 순위가 정해져요.

4최종 순위 발표

모든 게임이 끝나면 큰 화면에서 꼴찌부터 한 팀씩 공개해요. 우리 팀이 공개되는 순간 폰에도 최종 순위가 떠요.

7이럴 땐 이렇게

"진행 화면에 연결 중…"에서 넘어가지 않아요

진행자의 큰 화면이 켜져 있는지 확인하고, 잠시 기다려 주세요. 계속 안 되면 와이파이를 끄고 LTE로 바꾸거나 페이지를 새로고침해 보세요.

"연결이 끊겼어요"라고 떠요

자동으로 다시 연결돼요. 같은 폰·같은 인터넷 창이면 우리 팀 정보가 그대로 유지되니 다시 고를 필요 없어요.

"이미 있는 이름이에요"라고 떠요 (개인전)

같은 이름이 먼저 들어와 있어요. 홍길동2, 홍길동(영업)처럼 다르게 입력해 주세요.

흔들흔들이 안 돼요

아이폰은 게임 안내 화면에서 흔들기 센서 켜기를 누르고 허용해야 해요. 센서가 없는 폰은 자동으로 화면 연타로 바뀌어요.

소리가 안 나요

화면을 한 번 누르면 소리가 켜져요. 위쪽 🔊 버튼과 폰 무음 모드도 확인해 주세요.

폰이 가로로 돌아가요

폰을 세로로 들어 주세요. 화면 자동 회전을 끄면 편해요.

즐거운 시간 보내세요! 🎉
