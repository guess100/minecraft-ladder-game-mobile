# 팀 대항 오락실 (송년회 레크리에이션)

노트북 한 대 + 큰 화면(TV·빔프로젝터) + 참가자 스마트폰으로 진행하는 **팀 대항 미니게임 + 경품 추첨** 웹앱입니다.
설치·회원가입·서버 없이 정적 호스팅(GitHub Pages)만으로 동작합니다.

| 페이지 | 용도 |
|---|---|
| `index.html` | 시작 화면 (진행하기 / 경품 추첨 / 코드로 참가) |
| `host.html` | **진행 화면** — 노트북에서 열어 큰 화면에 띄움 |
| `play.html` | **참가자 화면** — 폰으로 QR 찍으면 열림 |
| `draw.html` | **경품 추첨** — 폰 없이 큰 화면만으로 |
| `ladder.html` | 기존 "블록 사다리 탐험" 게임 (보너스) |

## 진행 방법 (3단계)

1. 노트북 크롬에서 `host.html` 열기 → 큰 화면에 참가 QR과 방 코드 5자리가 뜸
2. 팀 대표가 폰으로 QR 찍고 팀 이름 입력 (팀원 폰은 같은 팀 선택 → 팀 점수는 평균)
3. 게임 고르고 **스페이스바** → 안내 → 3·2·1 → 실시간 중계 → 시상대 → 다음 게임
   마지막에 **최종 순위 발표**: 꼴찌부터 한 팀씩 공개 → 우승팀 왕관 + 폭죽

단축키: `Space`/`Enter`/`PageDown` 다음 진행(PPT 리모컨 OK) · `방향키` 게임 고르기 · `Q` 참가 QR 크게 · `F` 전체 화면 · `Esc` 뒤로

## 기능

- **미니게임 24종**: 연타왕, 박자왕, 흔들흔들, 문질문질, 두더지, 가위바위보, 100m 달리기, 피아노, 10초를 멈춰라, 레몬짜기, 순간포착, 탑 쌓기, 폭탄 해체, 장애물 피하기, 홀짝 계산기, 왼쪽 오른쪽, 색깔 풍선, 구구단 릴레이, 숫자 사냥, 반짝 기억, 금고 열기, 다른 색 찾기, 초성 퀴즈, 상식 퀴즈
- **점수 자동 집계**: 게임 순위대로 `전체 팀 수 − 순위 + 1`점 (동점은 같은 순위, 불참 0점). 같은 판은 모든 폰에 같은 문제/패턴이 나와 공정함
- **실시간 중계**: 막대 레이스 / 100m 트랙 / "결과는 끝나고 공개"(10초 멈춰라·순간포착)
- **진행 보조**: 직전 게임 결과 취소, 점수 보정(장기자랑·응원상 등), 팀 이름 변경·삭제, 팀 미리 만들기, 새 팀 생성 허용/차단
- **리허설 모드**: 설정에서 "가상 팀"을 추가하면 혼자서도 전체 흐름 연습 가능
- **끊김 대비**: 진행 노트북을 새로고침해도 팀·점수 유지(브라우저 저장), 폰은 자동 재연결
- **경품 추첨 10종**: 돌림판(120칸), 사다리(30명), 오리 경주, 로켓 레이스, 구슬 레이스, 슬롯머신, 캡슐 뽑기, 풍선 서바이벌, 스포트라이트, 바람 추첨기
  - 경품을 `커피 쿠폰 x5`처럼 적으면 위에서부터 차례로 추첨, 당첨자 자동 제외, "자리에 없음 → 다시 뽑기", 당첨자 목록 엑셀 복사
  - 최대 999명. 연출 인원보다 많으면 "본선 진출" 연출 후 진행 (당첨자는 항상 전체 명단에서 공정하게 먼저 뽑힘)

## 기술 메모

- 진행 노트북이 "서버" 역할을 합니다. 폰과는 **두 길을 동시에** 열고, 폰은 먼저 열린 쪽을 씁니다.
  1. 직접 연결: WebRTC(PeerJS). 연결 중개는 공개 PeerJS 서버(0.peerjs.com).
  2. 중계 연결: 공개 MQTT 브로커(`broker.emqx.io`, `broker.hivemq.com`, WebSocket/wss). 폰이 LTE라서 직접 연결이 막혀도 동작합니다. 팀 이름·점수가 이 외부 서버를 거쳐 가며, 무작위 방 코드로 구분됩니다.
  - 진행 화면 오른쪽 위에 `(직접✓ 중계✓)` 처럼 각 길의 상태가 표시됩니다.
  - 옵션: `?net=peer`(직접만) · `?net=relay`(중계만) · `?net=local`(같은 브라우저 탭끼리 테스트) · `?ps=호스트:포트/경로`(자체 PeerServer) · `?mqtt=wss://주소`(자체 브로커). QR 링크에 자동 전달됩니다.
- 회사 방화벽은 일부 포트를 막을 수 있으니 **행사장 인터넷으로 미리 리허설**하세요.
- 라이브러리: `vendor/peerjs.min.js`(PeerJS 1.5.4, MIT), `vendor/qrcode.js`(qrcode-generator 1.4.4, MIT). 효과음은 WebAudio로 합성(음원 파일 없음).
