1준비물과 행사 전 점검

준비물

  • 노트북 1대: 크롬 브라우저. 충전기를 꽂아 두세요. 배터리 절약 모드에서는 화면이 느려져요.
  • 큰 화면: TV나 빔프로젝터. 노트북과 HDMI로 연결하세요.
  • 인터넷: 노트북은 행사장 유선 인터넷이나 안정적인 와이파이에 연결하세요. 참가자 폰은 LTE·5G·와이파이 모두 괜찮아요.
  • 참가자 폰: 팀전이면 팀마다 1대를 권장해요. 그 폰으로 팀원이 돌아가며 출전하면 응원 열기가 가장 좋아요.

행사 전 체크리스트

  • 행사장에서 노트북으로 주소를 열고, 오른쪽 위에 ● 접속 0대 (Firebase)가 보이는지 확인
  • 폰 2~3대(와이파이 1대, LTE 1~2대)로 QR을 찍고 입장되는지 확인
  • 게임 하나를 처음부터 끝까지 해 보기
  • 노트북 절전 모드와 화면 꺼짐 끄기
  • 노트북 소리를 큰 화면이나 스피커로 내보내기 (효과음과 카운트다운 소리)
  • 팀전/개인전 중 무엇으로 할지 정하기 (사람들이 입장하기 전에)
💡 혼자 리허설하기 ⚙️ 팀 관리·설정에서 🤖 리허설용 가상 팀을 누르면 가짜 팀이 점수를 내 줘서, 폰 없이도 전체 흐름을 볼 수 있어요. 실제 행사 전에는 전체 초기화로 지워 주세요.

2시작하기 · 팀전/개인전 선택

  1. 노트북 크롬에서 https://guess100.github.io/minecraft-ladder-game-mobile/를 엽니다. 즐겨찾기에 저장해 두면 편해요.
  2. 게임 진행하기를 누르면 참가 접수 화면이 열려요. F를 누르면 전체 화면이 돼요.
  3. QR 옆에서 👥 팀전 또는 🙋 개인전을 고릅니다.
  4. 참가자들이 폰 카메라로 QR을 찍어 들어오면, 화면에 팀(사람) 이름이 하나씩 나타나요.
  5. 다 들어왔으면 게임 고르러 가기를 누르거나 Space를 누릅니다.
👥 팀전🙋 개인전
폰에서새 팀 이름을 만들거나, 이미 있는 팀을 눌러 합류자기 이름을 입력 (같은 이름은 받지 않아요)
최대16팀40명
점수팀원 폰들의 평균각자 자기 점수
⚠️ 모드는 미리 정하세요 모드를 바꾸면 그때까지의 참가자와 점수가 모두 지워지고, 참가자는 QR을 다시 찍어야 해요.
💡 QR을 못 찍는 사람이 있으면 같은 주소 첫 화면의 참가하기 칸에 방 코드 5자리를 입력하면 들어올 수 있어요. 늦게 온 사람도 언제든 같은 QR로 들어올 수 있어요. 화면 오른쪽 위의 작은 QR을 누르면 크게 보여요.

3게임 진행하기

한 게임은 고르기 → 안내 → 3·2·1 → 플레이 → 결과 순서로 진행돼요. 버튼을 누르거나 Space 하나로 다음 단계로 넘어갑니다.

① 게임 고르기

카드를 누르거나, 방향키로 고르고 Space를 누릅니다. 오른쪽에는 종합 순위가 보이고, 이미 한 게임에는 ✓ 1회 표시가 붙어요.

② 안내 → 시작

큰 화면과 참가자 폰에 똑같이 게임 방법이 떠요. 사회자가 방법을 읽어 준 뒤 ▶ 시작(Space)을 누르면 3·2·1 카운트다운 후 시작합니다.

③ 실시간 중계

팀별 점수가 막대 레이스로 실시간 올라가요. 오른쪽 위 원은 남은 시간이에요. 시간이 다 되면 자동으로 끝나요. 10초를 멈춰라, 순간포착은 긴장감을 위해 결과를 끝나고 공개해요.

④ 결과와 점수

📊 점수 규칙 게임마다 (전체 팀 수 − 순위 + 1)점을 받아요. 예를 들어 7팀이면 1등 +7점, 2등 +6점, … 7등 +1점이에요. 동점이면 같은 순위, 그 게임에 참가하지 않은 팀은 0점이에요. 모든 게임 점수를 합쳐 최종 순위를 정해요.

결과 화면에서 계속 → 게임 선택(Space)을 누르면 다음 게임을 고를 수 있어요.

4진행 중 쓰는 기능

버튼언제 쓰나요
📱 참가 QR 크게늦게 온 사람이 들어올 때. Q로도 열려요.
⚙️ 팀 관리·설정행사 이름 바꾸기, 팀전/개인전 바꾸기, 팀 이름 고치기·삭제, 팀 미리 만들기(예: 1조~8조), 참가자가 새 팀을 못 만들게 막기, 리허설용 가상 팀, 초기화
± 점수 보정장기자랑·응원상처럼 현장 이벤트 점수를 더하거나 뺄 때
↩ 직전 게임 결과 취소게임이 잘못 진행돼서 그 게임 점수를 없던 일로 할 때
⏹ 지금 종료하고 결과 보기플레이 중 시간을 다 기다리지 않고 바로 끝낼 때 (점수 반영)
중단 (점수 반영 안 함)플레이 중 문제가 생겨 이번 판을 없던 일로 할 때
🔊 ⛶오른쪽 위: 소리 켜기/끄기, 전체 화면
💡 노트북이 꺼지거나 새로고침해도 괜찮아요 팀과 점수는 노트북 브라우저에 자동 저장돼서 같은 노트북·같은 크롬으로 다시 열면 이어서 진행돼요. 참가자 폰도 자동으로 다시 연결돼요. 다른 노트북으로 바꾸거나 브라우저 기록을 지우면 처음부터 시작해요.

5최종 순위 발표

  1. 게임 선택 화면에서 🏆 최종 순위 발표를 누릅니다.
  2. Space(또는 다음 팀 공개)를 누를 때마다 꼴찌부터 한 팀씩 공개돼요.
  3. 마지막에 👑 우승팀 공개!를 누르면 두구두구 효과음 뒤에 우승팀이 왕관·폭죽과 함께 나와요.
  4. 참가자 폰에도 자기 팀이 공개되는 순간 최종 순위가 떠요.

발표 중 ← 취소를 누르면 게임 선택으로 돌아가 게임을 더 할 수 있어요.

6경품 추첨

첫 화면에서 경품 추첨을 누르면 열려요. 참가자 폰은 필요 없어요. 큰 화면만으로 진행합니다.

  1. 참가자: 이름이나 번호를 한 줄에 하나씩 넣어요. 엑셀에서 복사해 붙여넣어도 돼요. 번호로 채우기를 누르면 1번~N번이 자동으로 들어가요. 최대 999명이에요.
  2. 경품: 한 줄에 하나씩, 여러 개면 커피 쿠폰 x5처럼 적어요. 위에서부터 차례로 뽑아요. 보통 작은 경품부터 위에 적어요.
  3. 추첨 방법: 돌림판, 사다리, 오리 경주, 로켓 레이스, 구슬 레이스, 슬롯머신, 캡슐 뽑기, 풍선 서바이벌, 스포트라이트, 바람 추첨기 중에서 골라요.
  4. 추첨 시작(Space) → 당첨자가 나오면 ✓ 당첨 확정을 누르고, 당첨자가 자리에 없으면 🙅 자리에 없음 → 다시 뽑기를 눌러요.
  5. 끝나면 📋 엑셀로 복사로 당첨자 목록을 엑셀에 붙여넣을 수 있어요.
💡 당첨된 사람은 다음 추첨에서 자동으로 빠져요. 끄려면 체크를 해제하세요. 오른쪽 위 ☰ 설정(H)으로 왼쪽 설정 칸을 숨기면 추첨 화면이 커져요.

7휴대폰으로 진행하기

진행 화면과 경품 추첨은 휴대폰에서도 열려요. 휴대폰 크기에 맞게 세로로 정리되고, 진행 버튼은 화면 아래에 고정돼요.

  • 리허설이나 작은 모임에 좋아요.
  • 실제 행사는 모두가 큰 화면으로 점수를 보며 응원하는 게 재미라서 노트북 + 큰 화면을 권장해요.
  • 진행하는 휴대폰은 화면 자동 잠금을 꺼 두세요. 다른 앱으로 넘어가거나 화면이 꺼지면 잠깐 연결이 끊길 수 있어요.

10문제가 생겼을 때

참가자 폰이 "진행 화면에 연결 중"에서 넘어가지 않아요
  • 노트북 진행 화면이 열려 있는지, 오른쪽 위가 ● 접속 N대 (Firebase)인지 확인하세요.
  • 폰에서 와이파이를 껐다 켜거나 LTE로 바꿔 보세요.
  • 회사 보안망 와이파이는 막힐 수 있어요. 그럴 땐 LTE로 접속하게 하세요.
진행 화면에 "Firebase 권한 오류"가 떠요

Firebase 콘솔 → Realtime Database → 규칙 탭에 보안 규칙이 들어가 있고 게시되었는지 확인하세요. 규칙 내용은 저장소의 database.rules.json에 있어요.

노트북을 실수로 껐거나 새로고침했어요

같은 노트북·같은 크롬으로 다시 열면 팀과 점수가 그대로 있어요. 참가자 폰은 자동으로 다시 연결돼요. 진행 중이던 판은 사라지니 같은 게임을 다시 하면 돼요.

잘못 진행된 게임 점수를 없애고 싶어요

게임 선택 화면의 ↩ 직전 게임 결과 취소를 누르세요. 그보다 이전 게임이면 ± 점수 보정으로 직접 고쳐요.

팀 이름을 잘못 만들었어요 / 같은 팀이 두 개 생겼어요

⚙️ 팀 관리·설정에서 이름을 고치거나 필요 없는 팀을 삭제하세요. 삭제된 팀의 폰은 팀 선택 화면으로 돌아가요. 처음부터 팀 미리 만들기로 1조~8조를 만들고 "새 팀 만들기 허용"을 끄면 이런 일이 없어요.

몇 명까지 접속할 수 있나요?

동시에 폰 99대까지예요 (무료 Firebase 한도 100개 중 노트북 1개). 팀전은 팀당 폰 1대를 권장하고, 개인전은 40명까지 참가할 수 있어요.

새 행사를 처음부터 시작하고 싶어요

⚙️ 팀 관리·설정 → 점수만 초기화(팀은 유지) 또는 전체 초기화 (새 방)(팀·점수 모두 지우고 새 QR)를 누르세요.

소리가 안 나요

화면을 한 번 클릭하거나 키를 한 번 누르면 소리가 켜져요 (브라우저 정책). 오른쪽 위 🔊 버튼과 노트북 소리 출력 장치(HDMI/스피커)도 확인하세요.
