팀 대항 오락실 - 실행 방법
==========================

이 앱은 "웹 주소"로 열어야 폰이 QR로 들어올 수 있어요.
index.html 파일을 더블클릭해서 열면(file://) 진행 화면은 뜨지만 폰은 들어올 수 없어요.
아래 방법 중 하나로 띄우세요.


[방법 1] 가장 쉬움 - Netlify Drop (무료, 1분, https 주소가 바로 생김)
  1. https://app.netlify.com/drop 접속 (무료 회원가입 필요)
  2. zip을 푼 폴더를 통째로 화면에 끌어다 놓기
  3. 생긴 주소(https://xxxx.netlify.app)를 노트북 크롬으로 열기
  4. [게임 진행하기] → 큰 화면에 뜬 QR을 폰으로 찍기
  * 폰이 LTE여도, 와이파이여도 들어올 수 있어요.


[방법 2] 같은 와이파이 안에서만 - 노트북에서 직접 띄우기
  (노트북과 폰이 같은 와이파이에 있어야 해요)
  1. zip을 푼 폴더에서 터미널(명령 프롬프트) 열기
  2. 아래 명령 실행 (파이썬이 설치돼 있어야 함)
       python -m http.server 8000
  3. 노트북의 내부 IP 확인 (윈도우: ipconfig / 맥: 시스템 설정 > 와이파이 > 세부사항)
     예) 192.168.0.15
  4. 노트북 크롬에서 http://192.168.0.15:8000 으로 열기  ← localhost 말고 IP로 열어야
     QR 주소에도 IP가 들어가서 폰이 들어올 수 있어요.
  * http 주소라서 "흔들흔들" 게임의 흔들기 센서는 안 될 수 있어요 (화면 연타로 대체됨).


[방법 3] GitHub Pages (이미 올라가 있음)
  https://guess100.github.io/minecraft-ladder-game-mobile/


연결 방식 (자동)
  - 폰과 노트북은 두 길을 동시에 시도해서 먼저 되는 쪽을 써요.
    1) 직접 연결(WebRTC): 같은 와이파이면 빠르고 잘 됨
    2) 중계 연결(공개 MQTT 서버 경유): 폰이 LTE라 직접 연결이 막혀도 동작
  - 노트북 화면 오른쪽 위가 "● 접속 N대"(초록)이면 준비 완료예요.
  - 폰에서 계속 "연결 중"이면: 폰과 노트북을 같은 와이파이에 연결해 보세요.


단축키 (진행 화면)
  Space / Enter / PPT 리모컨 → 다음 진행
  Q → 참가 QR 크게 보기,  F → 전체 화면
