팀 대항 오락실 - 실행 방법 (다른 서버에 올리기)
================================================

이 앱은 서버 프로그램이 필요 없는 "정적 웹사이트"예요.
폴더 안의 파일을 웹 서버에 그대로 올리기만 하면 됩니다. (PHP·DB 설치 불필요)

  주의: index.html 을 더블클릭해서 열면(file://) 진행 화면은 뜨지만,
        폰이 QR로 들어올 수 없어요. 꼭 "웹 주소(http/https)"로 열어 주세요.


[폴더 구성]
  index.html          첫 화면
  host.html           진행 화면 (노트북·큰 화면)
  play.html           참가자 화면 (폰으로 QR 찍으면 열림)
  draw.html           경품 추첨
  guide.html          진행자 가이드
  player-guide.html   참가자 가이드
  ladder.html         보너스 게임 (블록 사다리)
  css/  js/  vendor/  화면·기능 파일 (반드시 같이 올려야 해요)
  js/firebase-config.js   Firebase 연결 설정
  database.rules.json     Firebase 보안 규칙 (서버에는 안 올려도 됨)
  README.md, FIREBASE_설정.md, 실행방법.txt   설명 문서 (서버에는 안 올려도 됨)


[방법 1] 회사·개인 웹 서버 (nginx, Apache, IIS 등)
  1. zip을 풀고 party-arcade 폴더 안의 내용을 웹 서버의 문서 폴더에 그대로 복사
     - 최상위(예: https://내도메인/)에 올려도 되고
     - 하위 폴더(예: https://내도메인/party/)에 올려도 돼요. 주소는 자동으로 맞춰져요.
  2. 브라우저로 https://내도메인/(올린 경로)/ 를 열어 [게임 진행하기]
  3. 큰 화면에 뜬 QR을 폰으로 찍어 입장 확인
  * https 를 권장해요. http 주소에서는 "흔들흔들" 게임의 흔들기 센서와
    화면 꺼짐 방지가 안 될 수 있어요 (흔들기는 화면 연타로 대체돼요).
  * 서버에 따로 설정할 것은 없어요. .html .js .css 파일만 제대로 열리면 됩니다.


[방법 2] Netlify Drop (무료, 1분, https 주소가 바로 생김)
  1. https://app.netlify.com/drop 접속 (무료 회원가입 필요)
  2. zip을 푼 party-arcade 폴더를 통째로 화면에 끌어다 놓기
  3. 생긴 주소(https://xxxx.netlify.app)를 노트북 크롬으로 열기


[방법 3] 노트북에서 직접 띄우기 (같은 와이파이 안에서만)
  1. party-arcade 폴더에서 터미널(명령 프롬프트) 열기
  2. 아래 명령 실행 (파이썬이 설치돼 있어야 함)
       python -m http.server 8000
  3. 노트북의 내부 IP 확인 (윈도우: ipconfig / 맥: 시스템 설정 > 와이파이 > 세부사항)
     예) 192.168.0.15
  4. 노트북 크롬에서 http://192.168.0.15:8000 으로 열기  ← localhost 말고 IP로 열어야
     QR 주소에도 IP가 들어가서 폰이 들어올 수 있어요.
  * 폰도 같은 와이파이에 있어야 이 주소를 열 수 있어요.

연결 방식 (Firebase)
  - 폰과 진행 화면은 구글 Firebase Realtime Database 를 거쳐 연결돼요.
    설정은 js/firebase-config.js 에 들어 있어요 (프로젝트: songyear-960a0).
  - 다른 서버에 올려도 같은 Firebase 프로젝트를 그대로 써요. 따로 바꿀 것 없어요.
  - 진행 화면 오른쪽 위가 "● 접속 N대 (Firebase)" 이면 준비 완료예요.
  - "Firebase 권한 오류"가 뜨면: Firebase 콘솔 > Realtime Database > 규칙 에
    database.rules.json 내용이 게시돼 있는지 확인하세요.
  - 무료 요금제 한도(동시 접속 100개)는 이 프로젝트를 쓰는 모든 서버가 함께 써요.
    여러 행사를 동시에 열 계획이면 행사별로 Firebase 프로젝트를 따로 만들고
    js/firebase-config.js 의 값을 바꿔 주세요 (방법: FIREBASE_설정.md).
  - 비상용: 주소 끝에 ?net=auto 를 붙이면 Firebase 없이 예전 방식
    (무료 공개 서버 경유)으로 열려요. 예) .../host.html?net=auto


팀전 / 개인전
  - 참가 접수 화면 위쪽에서 [팀전] 또는 [개인전]을 고르세요.
  - 팀전: 폰에서 팀 이름을 만들거나 기존 팀을 골라 합류 (최대 16팀)
  - 개인전: 폰에서 자기 이름으로 참가 (최대 40명)
  - 모드를 바꾸면 참가자와 점수가 초기화돼요. 사람들이 들어오기 전에 정하세요.


단축키 (진행 화면)
  Space / Enter / PPT 리모컨 → 다음 진행
  Q → 참가 QR 크게 보기,  F → 전체 화면
